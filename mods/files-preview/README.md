# Files Preview Mod

**Experimental; not ready for everyday use.** Based on Herdr Files at commit `7fe7ac34fef8a3ee76cb5d2f17bc8d6331e50bd8` under Apache-2.0 (see LICENSE). The native TextView/Source approach was informed by https://kt-tech.blog/blogs/herdr-app-mod-file-preview.

The macOS prototype provides HTML/Markdown TextView, text polling, a file action bar, Chrome, Save Copy and image/PDF previews (PDF limit: 30 pages). Remote files use an existing Herdr Core connection, Python 3 on remote Linux, 64 KiB chunks and SHA-256, with a 5 MiB per-file limit and symlink rejection. A failed transfer attempts to delete its partial staging directory.

Remote Chrome preview stages explicit relative HTML/CSS resources, including classic scripts and images, up to 64 files and 20 MiB total. Dynamic resources, ES modules, root-relative URLs, `<base>` and automatic Chrome refresh are unsupported. Browser rendering and interaction remain unverified. Old generated cache directories are pruned only on a later mod operation, not while idle. Save Copy chooses a destination folder and keeps the filename; GUI picker acceptance is incomplete. Windows is unsupported. There is no complete adversarial security or app-restart acceptance. TextView does not execute JavaScript or implement full CSS. Do not use for sensitive content or install in a daily environment until these boundaries are addressed. See [work evidence](../../docs/work/README.md).
