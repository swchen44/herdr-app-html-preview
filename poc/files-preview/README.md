# Files preview prototype — incomplete, do not install

Based on official Herdr Files `7fe7ac34fef8a3ee76cb5d2f17bc8d6331e50bd8`, Apache-2.0; see LICENSE. Preview/source approach informed by https://kt-tech.blog/blogs/herdr-app-mod-file-preview.

This prototype offers native HTML and Markdown text preview and source switching. A right-click shows an action bar with Preview, Chrome, and Save As; Chrome and save currently support only local paths. Image and PDF previews use macOS tools and an isolated app-home cache; PDF currently shows only the first page and image dimensions are fixed. Remote Chrome, save, images, PDF, relative resources and refresh are not implemented. Cache cleanup is not implemented. None of these user flows has been tested in a real GUI or remote Space. Not ready for installation.
